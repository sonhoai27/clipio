Power User Shortcuts

Master the keyboard to achieve peak productivity with our intuitive multi-select flow.

01 Basic Navigation

  • Move selection cursor
    ↑ ↓
  • Paste selected item Enter
  • Close Quick Paste Esc

02 Multi-Select Mode

  • Toggle item selection Space
  • Select range (Excel-style)
    Shift + ↑↓
  • Select all items
    ⌘ + A
  • Merge & Paste Selection Enter
